# 下载docker compose 
1、下载Docker Compose二进制文件：首先，确保你的系统上已经安装了curl工具。然后使用以下命令下载最新版本的Docker Compose二进制文件：
从公司服务器/usr/local/bin/，下载docker-compose，放置到目标服务器的/usr/local/bin/docker-compose

# 添加权限
2、添加执行权限：下载完成后，为Docker Compose二进制文件添加执行权限：
sudo chmod +x /usr/local/bin/docker-compose

# 软连接
3、创建软链接（可选）：为方便起见，你可以创建一个指向docker-compose的符号链接：
sudo ln -s /usr/local/bin/docker-compose /usr/bin/docker-compose

# 验
4、验证安装：最后，验证Docker Compose是否已成功安装，运行以下命令检查版本：
docker-compose --version
